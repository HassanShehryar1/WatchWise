# WatchWise

Browse popular movies, search movies and TV shows, and see where a title is streaming. Data comes from TMDB.

## Setup

1. Get an API key from https://www.themoviedb.org/settings/api
2. Copy `config.example.js` to `config.js` and put your key in it. `config.js` is ignored by git.
3. Open `index.html` in a browser.

## Tests

`node --test`
